一条命令开始

安装，然后保持更新。

自动识别 Linux / Windows 与 x64 / ARM64，校验 SHA-256，并在安装前停止进程、清理旧版本。

curl -fsS https://term.noxcaw.com/install | bash

装到 ~/.galdr/bin，并加入应用菜单和文件夹右键。装完请 source ~/.galdr/env 或新开终端。

从像素到进程

把终端该做的事，做完整。

不是套在系统 Shell 外的一层皮肤。渲染、Shell、会话和扩展能力在同一套清晰的边界里协作。

01 / RENDER

字形交给 GPU，细节留在像素里。

wgpu 实例化单元格渲染适配 HiDPI；CJK、emoji 和 IME 从一开始就是完整体验的一部分。

02 / SHELL
galdrcinclude bashrc

一个真正属于 Galdr 的 Shell。

默认进入 galdr-shell，只读取 galdrc。需要旧配置时再明确 include，不暗中继承环境。

03 / FLOW

标签、分屏，属于会话。

拖动排序、调整分栏、放大 pane。窗口只是附着层，工作状态不必随窗口消失。

04 / REMEMBER
detachwork / 3 tabs / 2 panesattach

关掉窗口，不等于丢掉现场。

恢复标签、分屏和目录；仍在运行的命令会在恢复前列出，由你决定是否继续。

ᚷGALDR PLUGIN API · V1

能力可以扩展，
信任必须有边界。

插件通过版本化协议接入命令、Shell、事件与声明式 UI。请求什么能力、授予什么能力，都清楚可见。

  • 进程插件在严格平台沙箱中运行
  • Wasm 组件有内存上限与执行期限
  • 原生插件必须显式信任
